# 2026 小米杯官方场地几何基线

来源：仓库上级目录中的官方《2026 年全国大学生计算机系统能力大赛—智能系统创新设计赛
小米杯赛题》PDF，正文“赛道布局”和第 3 页平面图。单位在配置中统一为米。

这份文件只固化官方固定结构，不代表真机场地已经验收。随机球、目标和障碍物位置必须由感知
确定；起点相对于 odom 的刚体变换必须在现场初始化。因此 `course_calibrated` 继续默认为 false。

## 坐标约定

- 图纸坐标系 `C`：原点位于全场外轮廓西南角，`+x` 向图纸右侧，`+y` 从起点指向终点，
  `z=0` 为场地地面。
- 里程计坐标系 `O`：启动后由真机 odom 给出，不假定与图纸重合。
- 现场初始化保存起点平移 `(o_x, o_y)` 和航向 `theta`；图纸点转换为 odom 点：
  `p_O = R(theta) * p_C + (o_x, o_y)`。
- 若起点姿态、尺度或航向置信度不足，控制器必须保持零输出；不得只用累计直线距离宣布赛段完成。

组保守默认值并执行键集合、正数、整数数量和结构关系校验。配置与代码不一致会被离线测试发现。

## 官方资料冲突

正文写黄色边沿宽 `0.15 m`、弯道部分 `0.10 m`；第 3 页图例写黄色边框宽 `0.10 m`。当前配置
将直线禁入裕量设为更保守的 `0.15 m`，弯道宽度记录为 `0.10 m`。现场只需向裁判核对该冲突，
不重新丈量整条场地。

## 尚不能从固定工程图替代的输入

- 每行每列一个橙球的当场排列；固定浅蓝球位置只用于排除，不用于猜橙球。
- 第四赛段三个目标、三个障碍物和球门的赛前随机位置。
- 起点放置误差、相机曝光/白平衡、odom 原点和航向漂移。
- 桥面、隧道和边界实物相对图纸的制造/铺设误差。

上述输入没有置信度时必须停步。工程图参数完成不等于 `course_calibrated=true`，更不等于六赛段
物理验收完成。
