调试模式

简单移动

比赛模式 默认锁定

正式比赛模式下，人工移动与姿态接口由后端关闭。仅限赛前维护时使用 --maintenance-controls 显式启用。

每次点击仅发送 0.25 秒低速脉冲；必须同时满足电量 ≥30%、未接充电线、enable_motion=True 和 run_allowed=true。物理测试建议从 ≥50% 开始。

操作顺序：起立 → START → 方向脉冲 → STOP。STOP 会锁定急停，必须重启进程后才能再次操作。

起立/趴下调用原厂姿态动作，不要求比赛运动总开关；但要求电量达标、未充电、已暂停/等待且运行许可为 false。趴下还必须通过地面与稳定性许可。
