# mi_dog

2026 年全国大学生计算机系统能力大赛——智能系统创新设计赛（小米杯）项目仓库。

本仓库用于存放四足机器人“荒野寻宝”赛题相关的代码、配置、技术文档与实验记录。

## 目录规划

- `src/`：项目源代码
- `config/`：运行与算法配置
- `launch/`：ROS 2 启动文件
- `scripts/`：开发、测试与部署脚本
- `docs/`：设计文档和比赛记录
- `extracted/`：本地比赛资料的文本解析结果
- `tests/`：测试代码

## 开发环境

- Ubuntu 20.04/22.04
- Docker
- ROS 2 Galactic
- Gazebo
- RViz 2
